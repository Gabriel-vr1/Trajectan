# Submission preparation

## Honest pitch draft

Trajectan turns synthetic football events into an explainable match experience. One reproducible tactical model drives the event stream, outcome forecasts and counterfactual branches. Every insight has a source state and evidence trail, and a deterministic publication gate rejects unsupported numbers. A unified Match Centre, investigation explorer, Scenario Lab and broadcast workspace adapt the same verified information for everyday viewers and analysts.

The working development build uses local persistence, a durable queue and a transparent deterministic explanation baseline. Microsoft Agent Framework and Foundry adapters implement three specialized roles; live Microsoft inference and Azure deployment still need verification before the submission can claim those integrations.
